# Global Music Streaming Trends Dashboard(Spotify Dataset)

## Project Overview

This project is an interactive Power BI dashboard developed to analyze global music streaming trends across different genres, countries, and tracks. The dashboard provides insights into streaming performance, viral popularity, and track trends using business intelligence and data visualization techniques.

The dashboard helps in understanding:
- Total music streams and viral scores
- Rising and falling track trends
- Genre-wise streaming performance
- Country-wise streaming distribution
- Track popularity and listener engagement

---

## Dashboard Features

### KPI Metrics
- Total Streams
- Average Viral Score
- Total Tracks
- Rising Tracks
- Trending Tracks

### Visualizations Included
- Genre-wise stream analysis
- Country and genre distribution map
- Track trend distribution
- Viral Score vs Streams scatter plot
- Top tracks by 7-day performance
- Funnel analysis for track conversion
- Decomposition tree analysis
- Genre contribution analysis
- Detailed track performance table

### Interactive Elements
- Dynamic filters for Genre, Country, Trend, and Popularity Category
- Multi-page dashboard navigation
- Interactive charts and drill-down analysis

## Key Insights

- Most tracks showed declining trends despite high viral scores.
- Pop and K-Pop genres generated the highest number of streams.
- Only a small percentage of tracks were categorized as trending.
- Viral popularity does not always guarantee high streaming performance.
- Streaming performance varied significantly across countries and genres.
